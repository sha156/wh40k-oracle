20 分、[[factions/死亡守卫/detachments/tallyband-summoners.md|Tallyband Summoners]] 分队。

## 效果

Each time a Plague Legions unit from your army is set up on the battlefield using the Deep Strike ability, if it is set up wholly within 12" of the bearer, it can be set up anywhere that is more than 6" horizontally away from all enemy models, instead of more than 8".

**分数**：20 分

## 携带限制

Death Guard model only.
