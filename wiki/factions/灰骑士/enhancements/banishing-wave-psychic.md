20 分、[[factions/灰骑士/detachments/brotherhood-strike.md|Brotherhood Strike]] 分队。

## 效果

Each time the bearer’s unit is set up using the Deep Strike ability, roll one D6 for each enemy unit within 12" of the bearer: on a 2-5, that unit suffers 1 mortal wound; on a 6, that unit suffers D3 mortal wounds.

**分数**：20 分

## 携带限制

GREY KNIGHTS model only.
